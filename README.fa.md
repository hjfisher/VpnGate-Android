# VpnGate-Android

نرم‌افزار اندرویدی برای دریافت و مرور لیست سرورهای عمومی **VPN Gate** با پشتیبانی از زبان فارسی (راست‌به‌چپ) و انگلیسی.

## امکانات

- **لیست زندهٔ سرورها** – دریافت آخرین سرورها به‌طور مستقیم از vpngate.net و استخراج خودکار کانفیگ OpenVPN آن‌ها.
- **حافظهٔ آفلاین** – هر دریافت به‌صورت محلی ذخیره می‌شود (در بین به‌روزرسانی‌ها جمع می‌شود و بر اساس IP تکراری حذف می‌گردد)، پس حتی بدون اینترنت هم لیست در دسترس است. وقتی اپ در حالت آفلاین داده‌های ذخیره‌شده را نشان می‌دهد، یک نوار هشدار نمایش داده می‌شود.
- **جستجو و مرتب‌سازی** – فیلتر با کلمهٔ کلیدی و مرتب‌سازی بر اساس سرعت (پینگ)، امتیاز یا کشور.
- **فیلتر بر اساس کشور** – انتخاب کشور از یک پنجره و نمایش فقط سرورهای همان کشور.
- **نشان نوع پروتکل** – هر سرور نوع پروتکل OpenVPN خود را نشان می‌دهد: `OVPN UDP`، `OVPN TCP` یا `OVPN UDP/TCP`.
- **اندازه‌گیری پینگ** – نمایش زمان پاسخ زندهٔ هر سرور.
- **علاقه‌مندی‌ها** – ستاره زدن سرورها و مشاهدهٔ آن‌ها در صفحهٔ اختصاصی علاقه‌مندی‌ها.
- **خروجی فایل `.ovpn`** – خروجی گرفتن کانفیگ‌ها در پوشهٔ `Download/VPNGate` (با MediaStore روی اندروید ۱۰ به بالا) برای ورود به اپ‌های OpenVPN.
- **حالت انتخاب گروهی** – انتخاب چند سرور برای حذف دسته‌ای، انتخاب همه یا خروجی گرفتن چند کانفیگ با هم.
- **مدیریت داده‌های ذخیره‌شده** – حذف یک سرور از صفحهٔ جزئیات آن، یا پاک‌کردن کل لیست از بخش تنظیمات.
- **رابط دو زبانه** – جابه‌جایی بین انگلیسی و فارسی (راست‌به‌چپ) از داخل خود برنامه.
- **طراحی مدرن** – رابط کاربری با Material 3 و Compose با چیدمان کارت‌های فشرده و تمیز.

## پیش‌نیازها / ساخت

```bash
git clone https://github.com/hjfisher/VpnGate-Android.git
cd VpnGate-Android
./gradlew assembleRelease
```
